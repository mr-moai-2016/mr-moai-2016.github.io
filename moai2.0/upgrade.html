はじめに

Moai UpgradeとはMoaiシステム全体を簡単に最新のバージョンにアップグレードするための仕組みです。

Moai Upgradeが使えない環境およびバージョンについて

Moai Upgrade は Android APK版 では現時点では使えません。 またMoai Ver2.0.2以前ではサポートされておりません。 上記の環境またはバージョンをお使いの方は、最新版Moaiを直接ダウンロードし、インストールして下さい。

Moai Upgrade は Ver2.3以降、新しい仕組みに移行したためUIが変更されています。
Ver2.3以降についてはこちらをご覧下さい。
Ver2.2以前についてはこちらをご覧下さい。

moai_profileを最新版のMoaiへ（Moai Upgradeを使わず）手動で継続したい場合、 こちらの記事を参考にしてください。
vtagファイル

Moaiインストールディレクトリ内には vtag ファイルというものが含まれており、このファイルの中身にバージョン番号が書かれてあります。 Moaiの内部システム的にはこれを真のバージョン番号として認識しています。

Moai Upgrade は、WebブラウザのMoaiエンジン設定の画面より現在のMoaiが最新バージョンであるかを確認し、 最新バージョンでなければ最新版の修正パッチを自動的にダウンロードし、上記の適用処理を自動的に行いますが、 vtagファイルの内容はこのときに参照されます。

Moai Upgrade の使い方（Ver2.3以降の場合）

以下に手順を述べます。
  1. Moaiトップページを開くと「Moai Upgrade」というリンクがあります。 このリンク先を開くと、Moai Upgradeの画面が表示されます。

  2. 更新の確認ボタンの直下にある表示を確認します。
    • Latest version.と表示される場合

      現在ご利用のMoaiは最新です。 現時点ではこれ以上何もする必要はありません。 Moaiのトップページに戻りましょう。

    • There is a new revision [X.Y.Z]. Please upgrade to it.と表示される場合

      現在ご利用のMoaiより新しいバージョンが存在します。 即ち、Moaiをより新しいバージョンにアップグレード可能であることを示します （X.Y.Zの部分が新しいバージョン番号を表します）。 この場合は、さらに次のステップへ進みます。

  3. Upgradeボタンを押します。

    必要なzipファイルがMoaiのリポジトリ（現在 https://github.com/mr-moai-2016/znk_rep）からダウンロードされ、 新しいファイル群が作業ディレクトリ（__birdman2_ws__/ws）に格納されます。 それが完了した後にMoai本体が自動的に停止します（起動した状態では自分自身を更新できないためです）。

    ただしMoaiは終了直前にbirdman2という子プロセスを生成し、これが続きの作業を行います。

    Moaiインストールディレクトリにあるファイルはtmpディレクトリなどを除き、全てバックアップディレクトリ（__birdman2_ws__/backup）へ移動され、 作業ディレクトリに格納されていた新しいファイル群がMoaiインストールディレクトリに全て適用されます。 これが無事終わるとMoai本体が自動的に再起動するはずです。

    役目を終えたbirdman2はここで終了します。

    最後に「[OK]: apply done.」のように表示されていれば成功です。

Moai Upgrade の使い方（Ver2.2以前の場合）

以下の３つのボタンを順番に押します。

  1. 最新バージョンの確認
  2. 修正パッチのダウンロード
  3. 修正パッチを適用

では以下にその手順を図等を例示しながら少し詳しく述べます。
  1. Moaiトップページを開くと「Moaiアップグレード」というリンクがあります。 このリンク先を開きます。

  2. 「最新バージョンの確認」ボタンを押します。 このとき、次の二通りのシナリオが考えられ、例えば次のように表示されます。
    • 現在ご利用のMoaiより新しいバージョンがない場合

      以下のように表示されると思います。 

      現在ご利用の Moai は最新バージョンのようです.
従ってMoaiアップグレードを行う必要は今はありません.

      現時点ではこれ以上は何もする必要がないことを意味します。 今はMoaiのトップページに戻りましょう。

      ただし現在Ver2.2よりも新しいMoaiが存在しますので、 この表示になることは（AndroidなどMoaiアップグレードがサポートされていない環境を除き）基本的にはないと思われます。

    • 現在ご利用のMoaiより新しいバージョンがある場合

      以下のように表示されると思います。 

      現在の Moai は Ver 2.X です.
Moai を Ver 2.X.Y へアップグレードすることができます.

まず最新版の修正パッチ(zipファイル)をダウンロードする必要があります.
(birdmanフォルダの直下にダウンロードされます).
「修正パッチのダウンロード」ボタンを押してください.

      Moaiを新しいバージョンにアップグレード可能であることを示します。 この場合は、さらに次のステップへ進みます。

  3. 「修正パッチのダウンロード」ボタンを押します。

    以下のように表示されると思います。 

    修正パッチ ... のダウンロードを開始します.
...
修正パッチのダウンロードは完了しました.

修正パッチを解凍します.
...
修正パッチの解凍は完了しました.

最後にこの修正パッチを実際に適用します.
(このときMoai本体の上書きも行われるため、古いMoaiプロセスが一旦終了し、新しいMoaiが起動します).
「修正パッチの適用」を押してください.

    ここでは、修正パッチを適用できる直前までの状態が整ったことが述べられています（実際にはまだ適用されていません）。

  4. 「修正パッチを適用」ボタンを押します。

    古いバージョンのMoaiフォルダ内に対し、新しいファイルのコピー処理などが行われます。 以下のように表示されると思います。 

    Birdman : ....
Birdman : ....
Birdman : ....
Birdman : ....
Birdman : ....
Birdman : OK. All upgrade is successfully done.

    またこのとき、一瞬Moai本体が終了し再度起動すると思います （これはMoai本体を上書きするためには、Moaiを一度終了させる必要があるためです）。

    最後に「OK. All upgrade is successfully done.」のように表示されていれば成功です。 念のため、Moaiのトップページに戻り、バージョンの表示されている部分が最新版の数字になっていることを確認してください （一番上にある「Welcome to Moai+Easter World」と書かれている部分のすぐ右です）。

Moaiを新規インストールした場合にmoai_profileをそれへ引き継ぐ方法

ここでは新しいMoaiをインストールした場合、古いMoaiでのmoai_profileを引き継ぐ方法について説明します。 moai_profileとは、登録されたEasterのリンク集やコレクションデータが格納された環境です。

PC版Moaiの場合


新しいMoaiのインストール先フォルダは、古いMoaiの moai_profile フォルダと同列の位置になるようにするのが、 一番簡単な引き継ぎ方だと思われます。 言い換えれば、新しいMoaiのインストール先フォルダを、古いMoaiのフォルダと同列になるようにインストールします （まあ普通はそうされると思います）。

このようにすることによって特に何も設定することなく、新しいMoaiでmoai_profileが引き続き使用できると思います。

この様子を念のために冗長に書きますと、以下のようになります。 例えば C:\znk_project というフォルダの下に、古いMoaiが以下のようにインストールされていたとします。 

	【フォルダ構成】
	moai-v2.2-win32
	moai_profile

新しいMoai の zip をダウンロードし、同フォルダに以下のように展開します。 これが上で言う「同列に置く」の意味です。 

	【フォルダ構成】
	moai-v2.2-win32
	moai-v2.3-windows
	moai_profile

moai-v2.3-windows の方の moai を起動し、問題がないことを確かめて下さい。 そして moai-v2.2-win32 の方については、もはや必要ないのであればこれを削除して頂いても構いません。 

	【フォルダ構成】
	moai-v2.3-windows
	moai_profile

Windows 32bit版を例に挙げましたが、他のプラットフォームでも同様です。 Linux環境ではこのドキュメント内での「フォルダ」という用語を「ディレクトリ」に読み替えてください。

尚、Ver2.3以降は、moaiの実行ファイルの本体はbinディレクトリ配下に配置されています。 例えばwindowsの場合、32bit版のexeはbin/windows-x86ディレクトリの直下、64bit版のexeはbin/windows-x64ディレクトリの直下にあります。 moai-v2.3-windows ディレクトリ内にこれらの両方を含むような状況もありえます。

Android APK版Moaiの場合


Android apk版では moai_profileの位置は通常、/sdcard/moai_profileに固定されているため、 あなたが特にこの位置を明示的に変更していない限りは、特に意識する必要はなくmoai_profileを新しいMoaiへ継続できると思います。
